# AINAS 用户手册

> 面向日常使用者：浏览媒体、管理相册、接入新目录。

## 一、登录

打开 http://localhost:8000，输入账号密码。首次部署的账号是 `admin`，密码见启动日志（或用 `backend/reset_password.py` 重设）。**登录后请立即在「设置」里修改密码。**

## 二、仪表盘

登录后的首页，四个统计卡片 + 两个信息卡：

- **图片 / 视频**：当前库内媒体总数。点击卡片可跳转媒体库并按类型筛选
- **相册 / 在线设备**：相册数量、已注册在线设备
- **最近任务**：最近 5 条扫描/上传任务及状态
- **设备状态**：在线设备的 CPU 占用

仪表盘每 30 秒自动刷新；切走再切回、或切换浏览器标签页也会立即刷新。标题右侧有手动「刷新」按钮。

## 三、媒体库（核心页面）

### 浏览

媒体库以网格展示缩略图（按需从原文件生成并缓存）。工具栏功能：

| 功能 | 说明 |
|------|------|
| 类型筛选 | 全部 / 图片 / 视频 |
| **高级搜索** | 按拍摄时间范围、相机、标签等条件组合查询 |
| **扫描目录** | 把一个新目录接入媒体库（见下） |
| **批量模式** | 多选后批量操作：加入相册、加标签、删除索引 |

滚动到底部自动加载更多（虚拟滚动）。

### 接入新目录（扫描）

1. 点工具栏 **扫描目录**
2. 输入目录路径：
   - 本地运行：宿主机真实路径，如 `E:/pic`
   - Docker：容器内路径（先把宿主目录挂载进容器）
3. 需要包含子目录就勾选"递归"
4. 点 **开始扫描**，面板会显示任务状态；完成后媒体库自动刷新

**扫描语义**：只建索引，不移动、不复制、不改原文件。重复扫描是增量的——已入库文件按哈希比对，只更新记录（实测 8,662 个文件重扫零重复）。删除索引不等于删除原文件。

### 上传

点 **上传** 按钮选择本地文件，上传到 NAS 存储（入库流程与扫描一致，同样提取 EXIF）。

### EXIF 与元数据

扫描时自动提取：拍摄时间、相机品牌/型号、GPS 信息（如有）、文件哈希。这些是高级搜索和相册归类的依据。

## 四、相册

相册是媒体的逻辑分组（不动原文件）：

- **创建相册**：相册页 → 新建，填名称和描述
- **加入相册**：媒体库批量模式 → 选中媒体 → 加入相册
- 仪表盘的相册卡片点击可跳转

## 五、任务

任务页查看全部扫描/上传/AI 任务的历史记录、状态和错误信息。扫描大目录时如果页面关了，任务仍在后台跑，回来看结果即可。

## 六、AI 功能（依赖部署形态）

| 功能 | 本地运行 | Docker |
|------|----------|--------|
| 自动标签 | 需完整依赖 | ✅ |
| 人脸识别 / 人脸相册 | 需 chromadb（Windows py3.13 无 wheel） | ✅ |
| 以图搜图 / 语义搜索 | 需 chromadb | ✅ |

> Windows 本地运行缺 chromadb 的 C++ 依赖 wheel，AI 入口会不可用；基础媒体管理不受影响。要用全套 AI 功能请用 Docker 部署（见 DEPLOYMENT.md）。

## 七、设置与账号

- **修改密码**：设置页 → 修改密码（需要旧密码）
- **审计日志**：管理员可查，记录关键操作

详见 [ADMIN_GUIDE.md](ADMIN_GUIDE.md)。

## 八、常见问题

见 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)，高频问题：

- 统计不更新 → 等 30 秒自动刷新或点刷新按钮
- 缩略图慢 → 首次按需生成，之后有缓存
- 扫描不到文件 → 检查路径写法（Docker 要用容器内路径）和格式是否支持
