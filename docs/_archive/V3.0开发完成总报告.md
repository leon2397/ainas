## 🎯 核心API端点

### 认证
- `POST /api/auth/login` - 登录
- `POST /api/auth/logout` - 登出
- `GET /api/auth/me` - 获取当前用户

### 媒体管理
- `GET /api/media` - 媒体列表
- `POST /api/media` - 上传媒体
- `GET /api/media/{id}` - 媒体详情
- `DELETE /api/media/{id}` - 删除媒体

### 相册
- `GET /api/albums` - 相册列表
- `POST /api/albums` - 创建相册
- `GET /api/albums/{id}` - 相册详情
- `POST /api/albums/{id}/media` - 添加媒体

### AI功能
- `POST /api/ai/face/detect` - 人脸检测
- `POST /api/ai/tags/auto` - 自动标签
- `GET /api/ai/albums/recommendations` - 智能推荐
- `POST /api/ai/similarity/compare` - 相似比较

### 生态化
- `GET /api/ecosystem/cloud/providers` - 云存储
- `GET /api/ecosystem/marketplace/plugins` - 插件市场
- `POST /api/ecosystem/mobile/devices/register` - 设备注册
- `POST /api/ecosystem/community/shares` - 创建分享

### 管理员
- `GET /api/admin/users` - 用户管理
- `GET /api/admin/audit/logs` - 审计日志
- `GET /api/admin/stats` - 系统统计
