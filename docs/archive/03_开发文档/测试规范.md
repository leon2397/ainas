## 📋 测试原则

### 核心原则

1. **端到端验证** - 不仅测试 API 返回，更要验证用户实际体验
2. **真实环境** - 在真实浏览器中手动验证，不能只依赖命令行测试
3. **回归测试** - 每次修改后必须重新执行完整测试流程
4. **文档同步** - 测试结果必须记录在备忘录中

### 测试分层

```
┌─────────────────────────────────────────────────────────┐
│  L4: 端到端测试 (E2E)                                    │
│  - 浏览器完整操作流程                                    │
│  - 真实用户场景验证                                      │
├─────────────────────────────────────────────────────────┤
│  L3: 前端集成测试                                        │
│  - 页面加载、JS 执行、DOM 渲染                           │
│  - 登录流程、Token 存储、页面跳转                         │
├─────────────────────────────────────────────────────────┤
│  L2: API 集成测试                                        │
│  - 多 API 联调（登录 → 获取数据 → 操作）                  │
│  - Token 传递、权限验证                                  │
├─────────────────────────────────────────────────────────┤
│  L1: API 单元测试（冒烟测试）                            │
│  - 单个端点是否响应                                      │
│  - HTTP 状态码验证                                       │
└─────────────────────────────────────────────────────────┘
```

## 🔧 测试自动化脚本

### 一键测试脚本

创建文件 `backend/tests/run_all_tests.ps1`：

```powershell
# AI-NAS Media Manager - 一键测试脚本
# 使用方法：.\run_all_tests.ps1

$ErrorActionPreference = "Stop"
$API_BASE = "http://localhost:8000"
$passed = 0
$failed = 0

Write-Host "========================================" -ForegroundColor Cyan
Write-Host "AI-NAS Media Manager 测试脚本" -ForegroundColor Cyan
Write-Host "========================================" -ForegroundColor Cyan

function Test-Endpoint {
    param($name, $url, $method = "GET", $body = $null, $token = $null)
    
    try {
        $headers = @{}
        if ($token) { $headers["Authorization"] = "Bearer $token" }
        
        if ($method -eq "GET") {
            $resp = Invoke-RestMethod -Uri $url -Method GET -Headers $headers -TimeoutSec 10
        } else {
            $resp = Invoke-RestMethod -Uri $url -Method POST -Headers $headers -Body $body -TimeoutSec 10
        }
        
        Write-Host "[PASS] $name" -ForegroundColor Green
        $script:passed++
        return $resp
    } catch {
        Write-Host "[FAIL] $name - $($_.Exception.Message)" -ForegroundColor Red
        $script:failed++
        return $null
    }
}

# T0 环境检查
Write-Host "`n[T0] 环境检查..." -ForegroundColor Yellow

if (Test-Path "..\backend\main.py") {
    Write-Host "[PASS] 后端代码存在" -ForegroundColor Green
    $passed++
} else {
    Write-Host "[FAIL] 后端代码不存在" -ForegroundColor Red
    $failed++
}

if (Test-Path "..\frontend\index.html") {
    Write-Host "[PASS] 前端代码存在" -ForegroundColor Green
    $passed++
} else {
    Write-Host "[FAIL] 前端代码不存在" -ForegroundColor Red
    $failed++
}

# T2 API 测试
Write-Host "`n[T2] API 冒烟测试..." -ForegroundColor Yellow

# T2.1 健康检查
Test-Endpoint "T2.1 健康检查" "$API_BASE/health"

# T2.2 登录
$loginBody = "username=admin&password=admin123"
$loginResp = Invoke-RestMethod -Uri "$API_BASE/api/auth/login" -Method POST -Headers @{"Content-Type"="application/x-www-form-urlencoded"} -Body $loginBody -ErrorAction SilentlyContinue

if ($loginResp -and $loginResp.access_token) {
    Write-Host "[PASS] T2.2 登录成功" -ForegroundColor Green
    $passed++
    $token = $loginResp.access_token
} else {
    Write-Host "[FAIL] T2.2 登录失败" -ForegroundColor Red
    $failed++
}

# T2.3-T2.9 使用 Token 测试
if ($token) {
    Test-Endpoint "T2.3 获取当前用户" "$API_BASE/api/auth/me" -token $token
    Test-Endpoint "T2.4 媒体列表" "$API_BASE/api/media/" -token $token
    Test-Endpoint "T2.5 设备列表" "$API_BASE/api/devices/" -token $token
    Test-Endpoint "T2.6 任务列表" "$API_BASE/api/tasks/" -token $token
    Test-Endpoint "T2.7 OCR 状态" "$API_BASE/ocr/status" -token $token
    Test-Endpoint "T2.8 云备份状态" "$API_BASE/cloud/status" -token $token
    Test-Endpoint "T2.9 系统监控" "$API_BASE/api/monitor/system" -token $token
}

# 结果汇总
Write-Host "`n========================================" -ForegroundColor Cyan
Write-Host "测试结果: $passed 通过, $failed 失败" -ForegroundColor $(if ($failed -eq 0) { "Green" } else { "Red" })
Write-Host "========================================" -ForegroundColor Cyan

if ($failed -gt 0) {
    exit 1
}
```

## 🚨 常见问题排查

### 登录后无法跳转

**症状**：登录成功，但页面停留在登录页

**排查步骤**：
1. F12 打开开发者工具 → Console
2. 查看是否有 JavaScript 错误
3. 检查 `document.querySelector(".sidebar")` 是否返回 null
4. 验证 index.html 结构完整性

**常见原因**：
- HTML 元素丢失（如 sidebar 被误删）
- JS 语法错误导致执行中断
- Token 未正确存储

### 中文乱码

**排查步骤**：
1. 检查文件编码（应为 UTF-8）
2. 检查 HTTP 响应头 `Content-Type: application/json; charset=utf-8`
3. 检查 PowerShell 编码 `[Console]::OutputEncoding`
