## 📋 概述

插件体系允许扩展 AI-NAS Media Manager 的功能，支持：
- **存储插件**: 连接不同的存储后端（本地、SMB、SSH、NAS）
- **AI插件**: 添加新的AI功能
- **UI插件**: 扩展前端界面
- **工具插件**: 添加辅助工具
- **集成插件**: 与第三方服务集成

## 🔧 插件类型

### 1. 存储插件 (StoragePlugin)

```python
from plugins.base import StoragePlugin, PluginManifest, PluginType

class MyStoragePlugin(StoragePlugin):
    
    @staticmethod
    def get_manifest() -> PluginManifest:
        return PluginManifest(
            id="my-storage",
            name="我的存储",
            version="1.0.0",
            description="描述...",
            author="作者",
            plugin_type=PluginType.STORAGE,
            tags=["storage"],
            config_schema={...}
        )
    
    def initialize(self) -> bool:
        """初始化插件"""
        return True
    
    def enable(self) -> bool:
        """启用插件"""
        return True
    
    def disable(self) -> bool:
        """禁用插件"""
        return True
    
    def cleanup(self) -> bool:
        """清理资源"""
        return True
    
    def connect(self) -> bool:
        """连接存储"""
        return True
    
    def disconnect(self) -> bool:
        """断开连接"""
        return True
    
    def list_files(self, path: str = "/") -> List[Dict]:
        """列出文件"""
        return []
    
    def upload_file(self, local_path: str, remote_path: str) -> bool:
        """上传文件"""
        return True
    
    def download_file(self, remote_path: str, local_path: str) -> bool:
        """下载文件"""
        return True
    
    def delete_file(self, remote_path: str) -> bool:
        """删除文件"""
        return True
```

## 🌐 API 端点

### 插件管理

| 方法 | 端点 | 说明 |
|------|------|------|
| GET | `/api/plugins/` | 列出所有插件 |
| GET | `/api/plugins/{plugin_id}` | 获取插件详情 |
| POST | `/api/plugins/{plugin_id}/enable` | 启用插件 |
| POST | `/api/plugins/{plugin_id}/disable` | 禁用插件 |
| POST | `/api/plugins/{plugin_id}/config` | 更新插件配置 |
| POST | `/api/plugins/install` | 安装插件 (上传ZIP) |
| DELETE | `/api/plugins/{plugin_id}` | 卸载插件 |

### 示例请求

```bash
# 列出插件
curl -X GET http://localhost:8000/api/plugins/ \
  -H "Authorization: Bearer <token>"

# 启用插件
curl -X POST http://localhost:8000/api/plugins/local-storage/enable \
  -H "Authorization: Bearer <token>"

# 上传安装插件
curl -X POST http://localhost:8000/api/plugins/install \
  -H "Authorization: Bearer <token>" \
  -F "file=@plugin.zip"
```

## 📥 安装插件

### 方式1: 上传 ZIP 包

1. 准备插件 ZIP 包（包含 manifest.json）
2. 在插件管理页面点击「安装插件」
3. 选择 ZIP 文件并上传

### 方式2: 手动安装

```bash
# 创建插件目录
mkdir -p backend/plugins/installed/my-plugin

# 复制插件文件
cp my-plugin/* backend/plugins/installed/my-plugin/

# 编辑 manifest.json
# 注册表会自动加载
```

## 🔒 安全机制

### 权限控制

插件需要声明所需的权限：
- `storage:read` - 读取存储
- `storage:write` - 写入存储
- `network:internet` - 访问互联网
- `system:admin` - 管理员功能

### 沙箱隔离

插件在受限环境中运行，无法直接访问系统核心。

### 2. 打包插件

```python
import zipfile
import os

def package_plugin(plugin_dir, output_zip):
    with zipfile.ZipFile(output_zip, 'w', zipfile.ZIP_DEFLATED) as zf:
        for root, dirs, files in os.walk(plugin_dir):
            for file in files:
                file_path = os.path.join(root, file)
                arcname = os.path.relpath(file_path, plugin_dir)
                zf.write(file_path, arcname)
```
