## 六、快速开始

### Windows 启动

```powershell
cd backend
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
python main.py
# 访问 http://localhost:8000
```

### ARM 设备部署

```bash
chmod +x arm/setup.sh
sudo ./arm/setup.sh --device-id "arm-01" --nas-path /nas
```

### Docker 部署

```bash
docker-compose up -d
```

### K8s 部署

```bash
kubectl apply -f k8s/
```
