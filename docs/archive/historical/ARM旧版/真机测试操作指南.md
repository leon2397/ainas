## 🟦 Part 3: ARM 设备测试

### 前提条件

| 条件 | 说明 |
|------|------|
| ARM 设备 | BM1688 / 瑞芯微 RK3588 / 其他 |
| 网络连接 | 与本机同一网络 |
| SSH 访问 | 需要 SSH 登录权限 |
| 存储空间 | 至少 10GB 可用 |

### 步骤 1: 远程连接

`powershell
# 1.1 SSH 连接到 ARM 设备
ssh user@arm-device-ip

# 示例：
ssh root@192.168.1.100

# 1.2 检查设备信息
uname -a
cat /proc/cpuinfo
df -h
`

### 步骤 2: 部署后端服务

`powershell
# 2.1 在 ARM 设备上创建项目目录
mkdir -p /opt/ai-nas-media-manager
cd /opt/ai-nas-media-manager

# 2.2 复制项目文件（从本机）
# 方式 A: 使用 SCP
scp -r C:\Users\leon23973\.qclaw\workspace\ai-nas-media-manager\* user@192.168.1.100:/opt/ai-nas-media-manager/

# 方式 B: 使用 Git（如果已提交）
git clone https://github.com/your-repo/ai-nas-media-manager.git

# 2.3 配置虚拟环境
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
`

### 步骤 3: 运行服务

`python
# 3.1 启动服务
python main.py

# 或使用 systemd 服务
sudo cp arm/ai-nas-arm.service /etc/systemd/system/
sudo systemctl enable ai-nas-arm
sudo systemctl start ai-nas-arm

# 3.2 检查服务状态
sudo systemctl status ai-nas-arm
`

### 步骤 4: 功能验证

`powershell
# 4.1 本机测试 ARM 服务
curl http://arm-device-ip:8000/health

# 4.2 媒体扫描测试
curl -X POST http://arm-device-ip:8000/api/media/scan -H \"Content-Type: application/json\" -d '{\"path\":\"/mnt/media\"}'

# 4.3 AI 功能测试（如果配置了 NPU）
curl http://arm-device-ip:8000/api/ai/status
`

### 步骤 5: 性能测试

`powershell
# 5.1 CPU 使用率
top -bn1 | head -20

# 5.2 内存使用
free -h

# 5.3 磁盘 I/O
iostat -x 1 5

# 5.4 网络带宽
iperf3 -s  # 在 ARM 设备上
iperf3 -c arm-device-ip  # 在本机上

## 🐛 问题排查

### 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 服务启动失败 | 端口被占用 | 检查 8000 端口，释放或更换端口 |
| 模块导入失败 | 依赖未安装 | pip install -r requirements.txt |
| 数据库错误 | SQLite 锁定 | 检查文件权限，关闭其他进程 |
| 前端无法访问 | 路径错误 | 检查前端文件路径 |
| Docker 构建失败 | 缺少依赖 | 检查 Dockerfile |
| ARM NPU 不可用 | 驱动未安装 | 安装 NPU 驱动 |

# Docker: docker logs ainas-backend
# ARM: journalctl -u ai-nas-arm -n 100
