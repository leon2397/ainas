## 📦 功能模块详解

### 1️⃣ 基础功能模块

#### 1.1 媒体管理
| 功能 | 说明 | 状态 |
|------|------|------|
| 媒体扫描 | 自动扫描指定目录的媒体文件 | ✅ |
| 媒体导入 | 支持批量导入照片/视频 | ✅ |
| 媒体预览 | 缩略图生成，支持多种格式 | ✅ |
| 媒体编辑 | 基础编辑（旋转、裁剪） | ✅ |
| 媒体删除 | 软删除/硬删除 | ✅ |
| EXIF读取 | 提取拍摄时间、地点、设备信息 | ✅ |
| 格式支持 | JPG/PNG/MP4/MOV/RAW等 | ✅ |

#### 1.2 相册管理
| 功能 | 说明 | 状态 |
|------|------|------|
| 相册创建 | 自定义相册，支持封面设置 | ✅ |
| 相册编辑 | 修改名称、描述、排序 | ✅ |
| 相册删除 | 删除相册（保留媒体） | ✅ |
| 智能相册 | 基于时间/地点/人物自动归类 | ✅ (V3.0) |
| 相册分享 | 生成分享链接 | ✅ (V3.0) |

#### 1.3 设备管理
| 功能 | 说明 | 状态 |
|------|------|------|
| 设备注册 | NAS/存储设备接入 | ✅ |
| 设备监控 | 在线状态、存储空间 | ✅ |
| 设备同步 | 多设备间媒体同步 | ✅ |
| 离线设备 | 离线设备管理 | ✅ |

#### 1.4 任务管理
| 功能 | 说明 | 状态 |
|------|------|------|
| 扫描任务 | 媒体扫描任务队列 | ✅ |
| AI任务 | 人脸识别、标签生成 | ✅ (V3.0) |
| 同步任务 | 云存储同步任务 | ✅ (V3.0) |

### 2️⃣ AI智能化模块 (V3.0 Phase 3)

#### 2.1 人脸识别
| 功能 | 说明 | 技术 |
|------|------|------|
| 人脸检测 | 检测照片中的人脸位置 | MTCNN/OpenCV |
| 人脸识别 | 识别具体人物 | FaceNet/Dlib |
| 人脸聚类 | 自动将同一人归为一组 | K-Means |
| 人脸标注 | 手动标注人物姓名 | - |
| NPU加速 | 国产芯片加速支持 | RK3588等 |

#### 2.2 智能相册推荐
| 推荐维度 | 说明 |
|----------|------|
| 时间维度 | 按日期/月份/年份推荐 |
| 地点维度 | 按地理位置聚合 (GPS) |
| 人物维度 | 按人物出现频率推荐 |
| 事件维度 | 识别聚会、旅行等事件 |
| 内容维度 | 风景、美食、宠物等 |

#### 2.3 自动标签
| 类别 | 标签数量 | 示例 |
|------|----------|------|
| 场景 | 15个 | 海滩、山脉、城市、室内 |
| 物体 | 20个 | 汽车、建筑、食物、动物 |
| 人物 | 18个 | 婴儿、儿童、群体、自拍 |
| 活动 | 15个 | 婚礼、运动、聚会、旅行 |

#### 2.4 相似图片检测
| 算法 | 用途 |
|------|------|
| 感知哈希 (pHash) | 检测视觉相似图片 |
| 平均哈希 (aHash) | 快速初筛 |
| 差值哈希 (dHash) | 检测细微差异 |
| 特征向量 | 深度学习相似度 |

### 3️⃣ 企业级功能模块 (V3.0 Phase 2)

#### 3.1 RBAC权限系统
| 角色 | 权限范围 |
|------|----------|
| Super Admin | 所有权限，系统配置 |
| Admin | 用户管理、系统管理、审计查看 |
| Operator | 媒体/相册/设备操作 |
| Viewer | 只读访问，不能修改 |
| Guest | 基础查看，受限功能 |

**权限类别 (30+种):**
- 媒体管理: 查看、上传、编辑、删除、下载
- 相册管理: 查看、创建、编辑、删除、分享
- 设备管理: 查看、添加、删除
- 用户管理: 查看、创建、编辑、删除
- 系统管理: 配置、监控、日志

#### 3.2 审计日志系统
| 审计类别 | 说明 |
|----------|------|
| AUTH | 登录/登出/认证失败 |
| USER | 用户增删改查 |
| MEDIA | 媒体操作记录 |
| ALBUM | 相册操作记录 |
| DEVICE | 设备操作记录 |
| SYSTEM | 系统配置变更 |
| CONFIG | 参数配置变更 |
| SECURITY | 安全相关事件 |
| ADMIN | 管理员操作 |

**审计级别:** DEBUG → INFO → WARNING → ERROR → CRITICAL
