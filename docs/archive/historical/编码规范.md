### 5. 错误处理

```python
# 推荐方式
try:
    result = await process_file(file_path)
except FileNotFoundError as e:
    logger.error(f"File not found: {e}")
    raise HTTPException(status_code=404, detail="File not found")
except Exception as e:
    logger.exception("Unexpected error")
    raise HTTPException(status_code=500, detail="Internal error")

# 不推荐方式
try:
    result = await process_file(file_path)
except:  # 捕获所有异常
    pass  # 静默处理
```

### 2. 代码风格

#### 变量声明
```javascript
// 推荐
const API_BASE = '/api';
let currentUser = null;

// 不推荐
var API_BASE = '/api';  // 避免使用 var
```

#### 函数定义
```javascript
// 推荐 - 箭头函数
const fetchMedia = async (params = {}) => {
    const response = await api.get('/media', { params });
    return response.data;
};

// 推荐 - 类方法
class MediaService {
    async getById(id) {
        return await api.get(`/media/${id}`);
    }
}
```

#### 异步处理
```javascript
// 推荐
try {
    const media = await fetchMedia({ limit: 10 });
    renderMediaList(media);
} catch (error) {
    console.error('Failed to fetch media:', error);
    showError('加载失败');
}

// 不推荐
fetchMedia({ limit: 10 })
    .then(media => renderMediaList(media))
    .catch(error => console.error(error));
```

## 提交规范

### Commit Message 格式

```
<type>(<scope>): <subject>

<body>

<footer>
```

#### Type

| 类型 | 说明 |
|------|------|
| feat | 新功能 |
| fix | 修复bug |
| docs | 文档更新 |
| style | 代码格式（不影响功能） |
| refactor | 重构 |
| test | 测试相关 |
| chore | 构建/工具相关 |

```
feat(media): 添加批量上传功能

- 显示上传进度条
- 支持拖拽上传

Closes #123
```

```

当token过期时，自动清除localStorage并重定向到登录页

Fixes #456
```

## 文件编码

### 强制要求

1. **所有文本文件必须使用 UTF-8 编码**
2. **不要添加 BOM（Byte Order Mark）**
3. **行尾使用 LF（\n），避免 CRLF（\r\n）**

### 检查编码

```bash
# 检查文件编码
file -i *.py

# 转换编码
iconv -f GBK -t UTF-8 input.txt > output.txt
```

### Git 配置

```bash
# 自动处理行尾
git config --global core.autocrlf input

# 设置默认编码
git config --global i18n.commitEncoding utf-8
git config --global i18n.logOutputEncoding utf-8
```

## 预提交检查

### 配置 Git Hooks

创建 `.git/hooks/pre-commit`：

```bash
#!/bin/bash

echo "Running pre-commit checks..."

# 检查 Python 代码
cd backend
ruff check . || exit 1
black --check . || exit 1

# 检查 JavaScript 代码
cd ../tests/e2e
npx eslint *.js || exit 1

echo "All checks passed!"
```

```bash
chmod +x .git/hooks/pre-commit
```

## 代码审查清单

### 提交前自检

- [ ] 代码通过 lint 检查
- [ ] 代码通过格式化
- [ ] 所有测试通过
- [ ] 新增功能有对应测试
- [ ] 文档已更新
- [ ] 无敏感信息泄露
- [ ] 无调试代码残留（print, console.log）

### 审查重点

1. **安全性**：SQL注入、XSS、敏感信息
2. **性能**：N+1查询、大数据量处理
3. **错误处理**：异常捕获、错误提示
4. **可维护性**：代码重复、复杂度过高
5. **测试覆盖**：关键路径是否有测试
