### Phase 2.1 - RBAC 权限系统

**核心组件：**

| 组件 | 文件 | 功能 |
|------|------|------|
| 权限管理器 | `backend/core/rbac/manager.py` | 角色权限管理、用户角色分配 |

**系统角色定义：**

| 角色 | 权限范围 |

- 相册管理权限 (5种)
- 设备管理权限 (3种)
- 用户管理权限 (4种)
- 系统管理权限 (4种)
- 审计权限 (2种)
- 管理员权限 (1种)

### Phase 2.2 - 审计日志系统

**核心组件：**

| 组件 | 文件 | 功能 |
|------|------|------|
| 审计日志器 | `backend/core/audit/logger.py` | 日志记录、查询、统计、导出 |
| 审计中间件 | `backend/middleware/audit/middleware.py` | 自动记录HTTP请求 |
| 审计初始化 | `backend/core/audit/__init__.py` | 模块导出 |

**审计功能：**

| 功能 | 说明 |
|------|------|
| **自动记录** | 所有HTTP请求自动记录 |
| **多级日志** | DEBUG/INFO/WARNING/ERROR/CRITICAL |
| **分类管理** | AUTH/USER/MEDIA/ALBUM/DEVICE/SYSTEM/CONFIG/SECURITY/ADMIN |
| **动作追踪** | 30+ 种审计动作 |
| **异步写入** | 缓冲区 + 异步写入 |
| **日志查询** | 支持多条件筛选 |
| **统计分析** | 按级别/类别/用户统计 |
| **导出功能** | JSON/CSV 格式导出 |

**审计动作：**
- 认证动作: login, logout, login_failed, password_change, token_refresh
- 用户动作: user_create, user_update, user_delete, role_assign, role_revoke
- 媒体动作: media_upload, media_delete, media_view, media_download, media_share
- 相册动作: album_create, album_delete, album_update
- 设备动作: device_register, device_unregister, device_command
- 系统动作: system_start, system_stop, backup_create, update_apply
- 安全动作: permission_denied, suspicious_activity, rate_limit_hit

## 🚀 使用方法

### 1. 权限检查

```python
from core.rbac import require_permission, Permission

@app.post("/api/media")
@require_permission(Permission.MEDIA_UPLOAD)
async def upload_media(request: Request):
    # 只有有上传权限的用户才能访问
    pass
```

### 2. 依赖注入

```python
from core.rbac import check_admin

@app.get("/api/admin/users")
async def list_users(current_user: dict = Depends(check_admin)):
    # 只有管理员能访问
    pass
```

### 3. 审计日志

```python
from core.audit import audit_logger, AuditAction

# 记录用户操作
await audit_logger.log_user(
    action=AuditAction.USER_CREATE,
    description="Created new user",
    user_id="admin_id",
    user_name="admin",
    details={"new_user": "john_doe"}
)
```

### 4. 管理员API

```bash
# 获取用户列表
curl http://localhost:8000/api/admin/users \
  -H "Authorization: Bearer $TOKEN"

# 查询审计日志
curl "http://localhost:8000/api/admin/audit-logs?days=7" \
  -H "Authorization: Bearer $TOKEN"

# 导出审计日志
curl -X POST http://localhost:8000/api/admin/audit-export \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"format": "json", "days": 7}'
```
