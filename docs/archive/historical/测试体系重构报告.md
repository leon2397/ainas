## 🚀 使用方法

### 运行所有测试
```powershell
.\run_tests.ps1
```

### 运行特定测试
```powershell
# 单元测试
.\run_tests.ps1 -TestType unit

# 集成测试
.\run_tests.ps1 -TestType integration

# E2E测试
.\run_tests.ps1 -TestType e2e

# 性能测试
.\run_tests.ps1 -TestType performance
```

### 带覆盖率
```powershell
.\run_tests.ps1 -Coverage
```

### 快速失败模式
```powershell
.\run_tests.ps1 -FailFast
```
