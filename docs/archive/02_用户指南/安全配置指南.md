## 🔐 新增安全功能

### 1. 用户认证（JWT）

**功能**：
- JWT Token 登录认证
- 密码 bcrypt 加密
- Token 过期机制（30分钟）
- 角色权限管理（admin/user）

**默认账户**：
- 用户名：`admin`
- 密码：`admin123`
- ⚠️ **生产环境必须修改！**

**API 接口**：
```
POST /auth/login          # 登录
GET  /auth/me             # 获取当前用户
POST /auth/change-password # 修改密码
POST /auth/logout         # 登出
GET  /auth/users          # 列出用户（管理员）
```

---

### 2. 密码加密

**功能**：
- 配置文件密码加密
- Fernet 对称加密
- 自动识别加密/明文

**使用方法**：
```python
from core.crypto import encrypt_password, decrypt_password

# 加密
encrypted = encrypt_password("my-secret-password")
# 结果: "encrypted:gAAAAAB..."

# 解密
decrypted = decrypt_password(encrypted)
# 结果: "my-secret-password"
```

---

### 3. API 限流

**功能**：
- 防止暴力破解
- 防止 DDoS 攻击
- 登录接口更严格限制

**限制规则**：
- 普通接口：60次/分钟
- 登录接口：10次/分钟
- 健康检查：不限流

**响应头**：
```
X-RateLimit-Limit: 60
X-RateLimit-Remaining: 45
```

---

### 4. 安全响应头

**自动添加**：
```
X-Content-Type-Options: nosniff
X-Frame-Options: DENY
X-XSS-Protection: 1; mode=block
Strict-Transport-Security: max-age=31536000; includeSubDomains
Content-Security-Policy: default-src 'self'
```

---

### 5. CORS 限制

**修改前**：
```python
allow_origins=["*"]  # 允许所有来源
```

**修改后**：
```python
allow_origins=["http://localhost:8000", "http://127.0.0.1:8000"]
```

## 🚀 快速开始

### 1. 安装新依赖

```powershell
cd backend
.\venv\Scripts\activate
pip install python-jose[cryptography] passlib[bcrypt] cryptography
```

### 2. 修改默认密码

编辑 `core/auth.py`：
```python
# 修改这行
self.users["admin"] = {
    "username": "admin",
    "hashed_password": self._hash_password("你的新密码"),
    ...
}
```

### 3. 修改加密密钥

编辑 `core/auth.py`：
```python
SECRET_KEY = "your-secret-key-change-in-production"
```

编辑 `core/crypto.py`：
```python
master_key = "ai-nas-default-key-change-in-production"
```

### 4. 启动服务

```powershell
python main.py
```

### 5. 测试登录

```bash
# 获取 Token
curl -X POST http://localhost:8000/auth/login \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "username=admin&password=admin123"

# 响应
{
  "access_token": "eyJhbGciOiJIUzI1NiIs...",
  "token_type": "bearer",
  "expires_in": 1800
}

# 使用 Token 访问受保护接口
curl http://localhost:8000/auth/me \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..."
```

## 🔧 生产环境配置

### 1. 修改密钥

```python
# core/auth.py
SECRET_KEY = os.getenv("JWT_SECRET_KEY", "your-secret-key")

# core/crypto.py
master_key = os.getenv("ENCRYPTION_KEY", "your-encryption-key")
```

### 2. 环境变量

```bash
# .env 文件
JWT_SECRET_KEY=your-256-bit-secret-key-here
ENCRYPTION_KEY=your-encryption-master-key-here
```

### 3. HTTPS 配置

```python
# main.py
uvicorn.run(
    "main:app",
    host="0.0.0.0",
    port=8000,
    ssl_keyfile="path/to/key.pem",
    ssl_certfile="path/to/cert.pem"
)
```

---

## ⚠️ 安全提醒

1. **生产环境必须修改默认密码**
2. **生产环境必须使用 HTTPS**
3. **密钥不要硬编码，使用环境变量**
4. **定期更换密钥和密码**
5. **启用防火墙限制访问**
