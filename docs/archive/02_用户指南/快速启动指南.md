# AI-NAS Media Manager - 快速启动指南

## 🚀 最快方式（推荐）

双击运行 `windows-deploy.bat`，脚本会自动：
1. 创建虚拟环境
2. 安装依赖
3. 启动服务

然后访问 http://localhost:8000

---

## 📋 环境要求

- Windows 10/11 (x64)
- Python 3.10+
- 4GB+ RAM

---

## 🛠️ 手动安装

### 1. 创建虚拟环境

```powershell
cd C:\leon\ai-nas-media-manager\backend
python -m venv venv
```

### 2. 激活环境

```powershell
.\venv\Scripts\activate
```

### 3. 安装依赖

```powershell
pip install -r requirements.txt
```

### 4. 启动服务

```powershell
python main.py
```

## ⚠️ 常见问题

### Python 命令找不到

确保 Python 已添加到 PATH，或使用完整路径：
```powershell
C:\Users\leon23973\AppData\Local\Programs\Python\Python312\python.exe
```

### 端口 8000 被占用

修改 `backend/core/config.py` 中的端口，或停止占用程序：
```powershell
netstat -ano | findstr :8000
taskkill /PID <pid> /F
```

### FFmpeg 未安装

安装 FFmpeg：
```powershell
winget install Gyan.FFmpeg
```
