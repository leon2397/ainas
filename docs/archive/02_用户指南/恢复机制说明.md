# AI-NAS Media Manager - 恢复机制说明

## 🛡️ 三重保护机制

### 第一重：ZIP备份（最简单）

**位置**：`C:\Users\leon23973\qclaw_backup`

**恢复方式**：
1. 双击 `一键恢复.bat`
2. 输入 `yes` 确认
3. 完成恢复

---

### 第二重：Git版本管理（最强大）

**功能**：
- 保存任意版本快照
- 查看版本历史
- 一键回退到任意版本

**使用方法**：

```powershell
# 查看状态
.\Git管理.bat

# 保存当前版本（修改代码后）
.\Git管理.bat -Action save
# 输入版本描述，如：修复了某bug

# 查看历史
.\Git管理.bat -Action list

# 回退到某个版本
.\Git管理.bat -Action restore
# 输入版本号
```

---

### 第三重：修改前备份（最安全）

**每次修改代码前**运行：

```powershell
.\before-edit.bat
```

这会自动创建带时间戳的备份。

## 🔄 恢复场景

### 场景1：代码改乱了，想全部重来

```
双击 → 一键恢复.bat → yes
```

### 场景2：只想回退某个文件

```powershell
.\Git管理.bat -Action restore
# 输入版本号
# 然后手动恢复单个文件
```

### 场景3：某个功能坏了，想保留其他修改

```powershell
# 先保存当前版本
.\Git管理.bat -Action save
# 输入：临时保存

# 回退到能工作的版本
.\Git管理.bat -Action restore
# 输入：能工作的版本号
```

### 场景4：删错了文件，想恢复

```powershell
# 在Git中查看删除记录
git log --diff-filter=D --summary

# 恢复文件
git checkout <commit> -- <deleted_file>
```
