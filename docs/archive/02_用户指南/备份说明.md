# AI-NAS Media Manager - 备份机制

## 🛡️ 防误删机制

### 自动备份

每次启动测试/修改前，系统会自动：
1. 创建带时间戳的备份
2. 保留最近 5 个备份版本
3. 备份存储在 `C:\Users\leon23973\qclaw_backup`

### 备份文件命名

```
ai-nas-media-manager_20260404_221029.zip    # 每日备份
ai-nas-media-manager_EDIT_20260404_221030.zip  # 修改前备份
```

---

## 📋 备份管理命令

### 1. 创建备份
```powershell
.\backup-manager.ps1 -Action backup
```

### 2. 查看备份列表
```powershell
.\backup-manager.ps1 -Action list
```

### 3. 恢复备份
```powershell
.\backup-manager.ps1 -Action restore
```

### 4. 修改前快速备份
```powershell
.\before-edit.bat
```

---

## 📁 备份存储位置

- 主备份目录：`C:\Users\leon23973\qclaw_backup`
- 项目备份目录：`C:\Users\leon23973\qclaw_backup\ai-nas-media-manager_*.zip`

---

## ⚠️ 重要提醒

1. **修改代码前先运行备份**：执行 `before-edit.bat`
2. **自动保留 5 个版本**：旧备份会自动清理
3. **恢复前会先备份当前版本**：不会丢失未保存的修改

---

## 🔄 恢复流程

1. 运行 `.\backup-manager.ps1 -Action restore`
2. 选择要恢复的备份版本
3. 系统会先备份当前版本再恢复
