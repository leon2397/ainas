## 🚀 快速开始

### Windows 启动

```powershell
# 双击运行
快速开始.bat

# 或手动
cd backend
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
python main.py
# 访问 http://localhost:8000
```

### ARM 设备部署

```bash
chmod +x setup.sh
sudo ./setup.sh --device-id "arm-01" --nas-path /nas
```

### Docker 部署

```bash
docker-compose up -d
```

### K8s 部署

```bash
kubectl apply -f k8s/
```
