# AI-NAS V7.0.0 开发环境启动指南

## 项目信息

- **版本**：V7.0.0
- **路径**：`D:\project\NAS\AI-NAS-V7.0.0`
- **技术栈**：Python 3.12 + FastAPI 0.115.5 + SQLite + ChromaDB

## 快速启动

### Windows 本地开发

```powershell
# 进入后端目录
cd D:\project\NAS\AI-NAS-V7.0.0\backend

# 创建虚拟环境（可选）
python -m venv venv
.\venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt

# 启动服务
python main.py

# 访问 http://localhost:8000
# 默认账号：admin / admin123
```

### Docker 部署

```bash
cd D:\project\NAS\AI-NAS-V7.0.0
docker-compose up -d
```

## 项目结构

```
AI-NAS-V7.0.0/
├── backend/          # 后端核心（Python + FastAPI）
│   ├── routes/       # API 路由（25 个文件，~200 端点）
│   ├── services/     # 业务服务（24 个文件）
│   ├── core/         # 核心模块
│   ├── database/     # 数据库层
│   └── plugins/      # 插件系统
├── frontend/         # 前端（HTML/CSS/JS）
├── docs/             # 文档
├── config/           # 配置文件
├── tests/            # 测试代码
├── deploy/           # 部署脚本
├── arm/              # ARM 设备适配
├── mobile/           # Flutter 移动端
└── scripts/          # 工具脚本
```
