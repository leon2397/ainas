## 📌 Phase 4 部署方案变更（重要）

**原计划**：Docker 化（因环境限制跳过）
**新计划**：方案 D - 传统部署 + 自动化脚本（pip + venv + systemd）

**理由**：
1. 本地和 ECS 网络环境差，Docker 镜像拉取困难
2. ECS 已在用 pip+systemd 方案，稳定运行
3. 商业化产品面向 ARM NAS 用户，pip 部署更通用
4. 可复用现有部署脚本资产
