## 一、加载性能优化

### 1.1 路由懒加载 (Lazy Loading)
```javascript
// 当前: 所有页面模块立即加载
import { dashboardPage } from './pages/dashboard.js';

// 优化后: 按需加载
const pageLoaders = {
    dashboard: () => import('./pages/dashboard.js'),
    media: () => import('./pages/media.js'),
    albums: () => import('./pages/albums.js'),
    // ... 其他页面
};

// 使用时
async showPage(pageName) {
    if (!this.pages[pageName]) {
        const module = await pageLoaders[pageName]();
        this.pages[pageName] = module[`${pageName}Page`];
    }
    this.pages[pageName].load();
}
```

### 1.2 资源缓存优化
- 添加 ETag/Last-Modified 响应头
- 静态资源使用 hash 版本化
- 配置 Cache-Control: max-age=31536000

### 1.3 关键 CSS 内联
将首屏必须的 CSS 直接嵌入 HTML head，减少请求。

## 四、稳定性优化

### 4.1 错误边界
```javascript
// 全局错误捕获
window.addEventListener('error', (e) => {
    console.error('Global error:', e.error);
    showToast('系统错误，请刷新页面', 'danger');
});
```

### 4.2 请求重试
```javascript
async function fetchWithRetry(url, options, maxRetries = 3) {
    for (let i = 0; i < maxRetries; i++) {
        try {
            return await fetch(url, options);
        } catch (e) {
            if (i === maxRetries - 1) throw e;
            await sleep(1000 * (i + 1));
        }
    }
}
```
