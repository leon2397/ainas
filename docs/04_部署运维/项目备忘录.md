### 目录结构
```
/root/ai-nas/                      ← 后端代码主目录（systemd 托管）
├── .env                           ← JWT + CORS 配置
├── venv/                          ← Python 3.11 虚拟环境
├── main.py (329行)
├── backend/                       ← 后端代码（与本地同步）
│   ├── routes/                    ← 24个路由文件
│   └── database/ / middleware/ / services/ / ai/
├── frontend/                      ← ⚠️ 未使用（FastAPI /static 挂载点空着）
├── config/                        ← 6个 yaml
├── data/ai_nas.db
├── logs/
└── deploy/ / arm/ / docs/ / k8s/ / scripts/ / tests/

/var/www/ai-nas/                   ← nginx 静态文件目录（生产用）
├── css/ / js/ / pages/ / index.html
└── ⚠️ 从本地 frontend/ 复制快照，需手动同步更新
```

### nginx 配置
- 静态文件（/css/、/js/、/pages/）：nginx 直接 serve `/var/www/ai-nas/`
- SPA 路由（/）：FastAPI 渲染
- API（/api/）：FastAPI
- 健康检查（/health）：FastAPI
- HTTP → HTTPS 自动重定向

### ⚠️ 待处理问题
- 相册功能不工作（NAS_PATH 未配置？ECS 无实际媒体文件？）
- 上传/下载功能不工作（上传目录/权限/nginx client_max_body_size 限制）
- 本地前端代码更新后需手动 `cp` 到 `/var/www/ai-nas/`
