# AI-NAS Media Manager - Windows 部署指南

## 环境要求

- Windows 10/11 (x64)
- Python 3.10+
- 4GB+ RAM
- 10GB+ 可用磁盘空间

## 快速部署

### 1. 安装 Python

如果没有安装 Python，从 [python.org](https://www.python.org/downloads/) 下载安装。

确保安装时勾选：
- ✅ Add Python to PATH
- ✅ Install pip

### 2. 安装 Git (可选)

从 [git-scm.com](https://git-scm.com/download/win) 下载安装。

### 3. 创建虚拟环境并安装依赖

打开 PowerShell：

```powershell
# 进入项目目录
cd C:\leon\ai-nas-media-manager\backend

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
.\venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt
```

### 4. 配置

编辑配置文件：

```powershell
# 编辑全局配置
notepad ..\config\global.yaml

# 编辑设备配置
notepad ..\config\devices.yaml
```

### 5. 启动服务

```powershell
# 在 backend 目录下
python main.py
```

### 6. 访问

- 前端界面: http://localhost:8000
- API 文档: http://localhost:8000/docs

## Windows 服务化 (可选)

使用 NSSM 将服务注册为 Windows 服务：

```powershell
# 下载 nssm
winget install nssm

# 创建服务
nssm install ai-nas "C:\leon\ai-nas-media-manager\backend\venv\Scripts\python.exe" "C:\leon\ai-nas-media-manager\backend\main.py"

# 启动服务
nssm start ai-nas
```

## 常见问题

### Q: Python 命令找不到

确保 Python 已添加到 PATH，或使用完整路径：
```powershell
C:\Users\leon23973\AppData\Local\Programs\Python\Python312\python.exe
```

### Q: pip install 失败

更新 pip 后重试：
```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### Q: 端口被占用

修改 `config/global.yaml` 中的端口，或停止占用程序：
```powershell
netstat -ano | findstr :8000
taskkill /PID <pid> /F
```

### Q: 数据库初始化失败

确保 data 目录存在：
```powershell
mkdir data
mkdir data\uploads
mkdir data\thumbnails
```

## 验证安装

启动后访问以下端点确认服务正常：

```powershell
# 健康检查
curl http://localhost:8000/health

# 获取状态
curl http://localhost:8000/status

# 列出设备
curl http://localhost:8000/api/devices/
```
