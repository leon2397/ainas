## 服务启动问题

### 症状
- 运行 `python main.py` 报错
- 服务启动后立即退出
- 端口被占用错误

### 排查步骤

#### 步骤1：检查Python环境

```powershell
# 检查Python版本（需要3.10+）
python --version

# 检查Python路径
where python

# 检查虚拟环境
.\venv\Scripts\activate
which python
# 应该显示 venv 路径
```

**问题**：Python版本过低
**解决**：安装 Python 3.10 或更高版本

#### 步骤2：检查依赖

```powershell
# 激活虚拟环境
.\venv\Scripts\activate

# 检查关键依赖
pip list | findstr fastapi
pip list | findstr uvicorn
pip list | findstr aiosqlite

# 如果缺失，重新安装
pip install -r requirements.txt
```

**问题**：依赖缺失
**解决**：`pip install -r requirements.txt`

#### 步骤3：检查端口占用

```powershell
# 查看端口占用
netstat -ano | findstr :8000

# 查看占用进程
tasklist | findstr <PID>

# 结束占用进程
taskkill /PID <PID> /F
```

**问题**：端口被占用
**解决**：结束占用进程或修改端口

#### 步骤4：检查配置文件

```powershell
# 检查配置文件是否存在
ls config/

# 检查配置格式
python -c "import yaml; yaml.safe_load(open('config/global.yaml'))"
```

**问题**：配置格式错误
**解决**：恢复默认配置或修复YAML格式

#### 步骤5：查看详细错误

```powershell
# 运行并捕获错误
python main.py 2>&1 | tee startup.log

# 查看Python traceback
python -u main.py
```

## 登录问题

### 症状
- 提示用户名或密码错误
- 登录后自动退出
- Token过期

### 排查步骤

#### 检查1：确认默认账户

默认账户：
- 用户名：`admin`
- 密码：`admin123`

**注意**：区分大小写

#### 检查2：检查认证服务

```powershell
# 测试登录API
curl -X POST http://localhost:8000/auth/login `
  -H "Content-Type: application/x-www-form-urlencoded" `
  -d "username=admin&password=admin123"

# 应该返回 token
```

#### 检查3：检查Token

```powershell
# 获取token
$token = (curl -X POST http://localhost:8000/auth/login -d "username=admin&password=admin123" | ConvertFrom-Json).access_token

# 使用token访问
curl http://localhost:8000/auth/me -H "Authorization: Bearer $token"
```

#### 检查4：重置密码

如果忘记密码，需要重置：

```python
# 临时修改代码 core/auth.py
# 修改后重启服务
self.users["admin"]["hashed_password"] = self._hash_password("新密码")
```

## 性能问题

### 系统运行缓慢

#### 症状
- 界面加载慢
- 操作响应延迟
- CPU/内存占用高

#### 排查

```powershell
# 1. 检查系统资源
# CPU
wmic cpu get loadpercentage

# 内存
wmic OS get TotalVisibleMemorySize,FreePhysicalMemory

# 磁盘
wmic logicaldisk get size,freespace,caption

# 2. 检查Python进程资源占用
tasklist | findstr python

# 3. 检查并发任务数
# 查看任务中心

# 4. 检查数据库大小
ls -lh data/metadata.db
```

#### 解决

- 关闭不必要的任务
- 增加系统内存
- 清理磁盘空间
- 优化数据库（添加索引）
- 重启服务

---

### 数据库查询慢

#### 症状
- 媒体列表加载慢
- 搜索响应慢
- 数据库CPU占用高

#### 排查

```python
# 1. 启用慢查询日志
# 在 database/db.py 中设置
SLOW_QUERY_THRESHOLD = 100  # ms

# 2. 检查查询计划
# 使用 SQLite 命令行
sqlite3 data/metadata.db
EXPLAIN QUERY PLAN SELECT * FROM media WHERE type='image';
```

#### 解决

```sql
-- 添加索引
CREATE INDEX idx_media_type ON media(type);
CREATE INDEX idx_media_created ON media(created_at DESC);
CREATE INDEX idx_media_hash ON media(file_hash);

-- 分析表
ANALYZE;

-- 优化数据库
VACUUM;
```

## 数据问题

### 数据库损坏

#### 症状
- 提示数据库错误
- 无法读取数据
- 服务崩溃

#### 排查

```powershell
# 1. 检查数据库文件
ls -lh data/metadata.db

# 2. 检查数据库完整性
sqlite3 data/metadata.db "PRAGMA integrity_check;"

# 3. 尝试修复
sqlite3 data/metadata.db ".recover" | sqlite3 data/metadata_fixed.db
```

#### 解决

```powershell
# 1. 备份当前数据库（即使损坏）
copy data\metadata.db data\metadata.db.corrupt

# 2. 从备份恢复
一键恢复.bat

# 3. 或重新初始化
# 删除数据库后重启服务会自动创建
```
