## 📅 每日操作

### 1. 启动服务


```powershell

.\backup-manager.ps1 -Action list
```

## 🔧 每月操作

### 1. 完整备份

```powershell
# 1. 创建完整备份
.\backup-manager.ps1 -Action backup

# 2. 清理旧备份（自动保留5个）
# 已有自动清理机制

# 3. 检查备份完整性
.\backup-manager.ps1 -Action list
```

### 2. 代码版本更新

```powershell
# 保存当前版本
.\Git管理.bat -Action save
# 输入：月度快照 + 月份

# 查看版本历史
.\Git管理.bat -Action list
```

### 3. 依赖更新检查

```powershell
.\venv\Scripts\activate
pip list --outdated
pip install -r requirements.txt --upgrade
```

### 4. 日志清理

```powershell
# 查看日志大小
ls logs\

# 清理30天前的日志
python -c "from services.logger import get_logger; get_logger().cleanup_old_logs(30)"
```
