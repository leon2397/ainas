## 系统安装

### 环境要求

| 组件 | 最低要求 | 推荐配置 |
|------|----------|----------|
| CPU | 4核 | 8核+ |
| 内存 | 8GB | 16GB+ |
| 磁盘 | 100GB | 500GB+ SSD |
| 网络 | 100Mbps | 1Gbps |
| Python | 3.10 | 3.12 |

### 安装步骤

```powershell
# 1. 安装 Python 3.12
# 下载: https://www.python.org/downloads/
# 安装时勾选 "Add Python to PATH"

# 2. 克隆/解压项目
cd C:\
git clone <repository-url> ai-nas-media-manager
# 或解压 zip 文件

# 3. 创建虚拟环境
cd ai-nas-media-manager\backend
python -m venv venv

# 4. 激活环境
.\venv\Scripts\activate

# 5. 安装依赖
pip install -r requirements.txt

# 6. 初始化数据库
python -c "import asyncio; from database.db import db; asyncio.run(db.init())"

# 7. 启动服务
python main.py
```

### 服务配置

创建 Windows 服务（可选）：

```powershell
# 使用 nssm 创建服务
nssm install AI-NAS "C:\leon\ai-nas-media-manager\backend\venv\Scripts\python.exe"
nssm set AI-NAS AppDirectory "C:\leon\ai-nas-media-manager\backend"
nssm set AI-NAS AppParameters "main.py"
nssm start AI-NAS
```

当前版本为单用户系统，默认账户：
- 用户名：admin

### 修改默认密码

```python
# 方法一：通过界面
# 登录后 -> 系统设置 -> 修改密码

# 方法二：修改代码
# core/auth.py
self.users["admin"]["hashed_password"] = self._hash_password("新密码")
```

### 添加用户（需修改代码）

```python
# core/auth.py
self.users["newuser"] = {
    "username": "newuser",
    "hashed_password": self._hash_password("password"),
    "disabled": False,
    "role": "user"  # admin/user
}
```

## 存储管理

### 存储类型

| 类型 | 用途 | 配置 |
|------|------|------|
| Local | 本地磁盘 | 默认 |
| SMB | Windows共享 | 需配置用户名密码 |
| SSH | Linux远程 | 需配置密钥 |

### 添加SMB存储

```yaml
# config/devices.yaml
storage_providers:
  - name: nas_smb
    type: smb
    host: 192.168.1.100
    share: photos
    username: nasuser
    password: encrypted:xxx
    domain: WORKGROUP
```

### 添加SSH存储

```yaml
storage_providers:
  - name: linux_server
    type: ssh
    host: 192.168.1.101
    port: 22
    username: root
    key_path: ~/.ssh/id_rsa
    # 或密码
    # password: encrypted:xxx
```

## 设备管理

### 设备发现

系统支持自动发现局域网内的ARM设备：
- 使用UDP广播
- 默认端口：8765
- 发现间隔：30秒

### 手动添加设备

```yaml
# config/devices.yaml
devices:
  - id: arm-001
    name: "客厅ARM盒子"
    host: 192.168.1.200
    port: 8080
    type: bm1688
    capabilities:
      - ai_inference
      - video_decode
    status: active
```

### 负载均衡配置

```yaml
# config/ai_engine.yaml
load_balancer:
  strategy: least_loaded  # least_loaded | round_robin | random
  health_check_interval: 30
  timeout: 10
```

```python

uvicorn.run(
    "main:app",
    host="0.0.0.0",
    port=443,
    ssl_keyfile="/path/to/key.pem",
    ssl_certfile="/path/to/cert.pem"
)
```

或使用Nginx反向代理：

```nginx
server {
    listen 443 ssl;
    server_name ai-nas.local;
    
    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;
    
    location / {
        proxy_pass http://localhost:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 故障处理

### 服务无法启动

1. 检查日志：`logs/error.log`
2. 检查端口占用：`netstat -ano | findstr :8000`
3. 检查依赖：`pip list`
4. 检查配置：`config/global.yaml`

### 数据库连接失败

1. 检查数据库文件权限
2. 检查磁盘空间
3. 尝试修复：`sqlite3 metadata.db ".recover"`

### 内存不足

1. 减少并发工作线程
2. 增加虚拟内存
3. 分批处理大任务

### 磁盘空间不足

1. 清理日志：`logs/cleanup.py`
2. 清理缩略图缓存
3. 移动数据到外部存储
