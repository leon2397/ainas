## 一、项目概述

AI-NAS Media Manager 是一款面向 ARM 设备的私有媒体管理与 AI 智能相册系统。支持人脸识别、自动标签、智能相册、相似度去重、视频处理等 AI 功能，面向群晖/威联通/树莓派/Jetson 等 NAS 及边缘设备，定位为商业化 SaaS 产品的开源底座。

### 核心技术栈

| 层级 | 技术 |
|------|------|
| 后端 | Python 3.11 + FastAPI + Uvicorn |
| 数据库 | SQLite（ai_nas.db）+ ChromaDB 向量库 |
| 前端 | 原生 HTML/CSS/JS（无框架） |
| AI 推理 | ONNX Runtime + CPU Fallback |
| 媒体处理 | FFmpeg |
| 存储抽象 | SMB/SMB3 协议支持 |
| 容器化 | Docker + Docker Compose |
| 部署 | systemd 守护 + Nginx 反向代理 |
| CI/CD | GitHub Actions |
| 移动端 | Flutter（Dart）|
| 小程序 | 微信小程序 |
