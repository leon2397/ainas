# ADR-001: 以 V7.0.0 为重建基底

- **状态**：已接受
- **日期**：2026-10-18
- **决策者**：项目负责人

## 背景

D 盘工作区存在同一项目的 4 份代码：AI-NAS 根目录（770 文件）、NAS/AI-NAS-V7.0.0、AIqizhi/ 多版本快照、910/ 备份。各版本完成度与验证状态不明，需要选定唯一重建基底。

## 决策

选定 **V7.0.0** 为唯一重建基底，其余副本全部归档。

## 理由

1. **唯一生产验证版**：V7 是唯一在群晖/威联通实测跑过的版本（历史评估 4.30 分），其余版本停留在文档与半成品
2. **功能最完整**：FastAPI 后端 167 个 py 文件、前端、Docker、K8s、deb/rpm 打包资产齐全
3. **V8 是蓝图不是产品**：V8 只有设计文档（硬件盒子方向），无可运行代码
4. 资产评估报告（2026-09-09）独立得出同一结论，交叉验证

## 实施方式

从 V7 拣选真产品文件组装 `D:\pro1\ainas`：剔除约 150 个开发一次性脚本（check_*/fix_*/verify_*）、venv-test、截图、部署 zip、运行时数据与敏感配置，得 372 个受版本管理文件。

## 后果

- 组装后立即冒烟验证，暴露并修复 9 个 V7 遗留缺陷（见 TROUBLESHOOTING.md 第三节）
- V6 及更早版本文档进 archive/，仅供追溯
- 后续所有开发只认 `D:\pro1\ainas` 这一个代码库
