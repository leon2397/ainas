## 功能详解

### 3.1 媒体扫描

**功能**：自动扫描指定目录的媒体文件

**操作步骤**：
1. 进入"任务中心"
2. 点击"新建扫描任务"
3. 选择扫描路径
4. 配置选项：
   - 递归扫描子目录
   - 包含视频文件
   - 生成缩略图
5. 开始扫描

**支持的格式**：
- 图片：JPG, PNG, GIF, BMP, WebP, HEIC, RAW
- 视频：MP4, AVI, MOV, MKV, WebM

### 3.2 AI分类

**功能**：使用AI自动识别图片内容并分类

**操作步骤**：
1. 选择要分类的媒体
2. 点击"AI分类"
3. 选择AI引擎（CPU/NPU）
4. 开始分类

**分类结果**：
- 人物
- 风景
- 动物
- 食物
- 建筑
- 文档
- 其他

### 3.3 去重检测

**功能**：检测并删除重复媒体文件

**操作步骤**：
1. 进入"任务中心"
2. 点击"去重检测"
3. 设置相似度阈值（默认85%）
4. 开始检测

**处理方式**：
- 查看重复组
- 保留最佳质量
- 删除重复文件
- 或仅标记不删除

### 3.4 相册生成

**功能**：创建虚拟相册（软链接，不复制文件）

**操作步骤**：
1. 选择媒体文件
2. 点击"添加到相册"
3. 选择或创建相册
4. 生成相册

**相册类型**：
- 时间相册（按日期）
- 地点相册（按GPS）
- 人物相册（按人脸识别）
- 自定义相册

### 3.5 搜索功能

**全文搜索**：
- 支持文件名搜索
- 支持标签搜索
- 支持EXIF信息搜索

**高级搜索**：
- 按日期范围
- 按文件类型
- 按文件大小
- 按拍摄设备

**搜索语法**：
```
# 基本搜索
风景

# 标签搜索
tag:人物

# 日期搜索
date:2024-01-01..2024-12-31

# 组合搜索
tag:风景 AND date:2024
```

## 常见问题

### Q1: 如何修改默认密码？

**A**: 
1. 登录系统
2. 进入"系统设置"
3. 点击"修改密码"
4. 输入旧密码和新密码
5. 保存

### Q2: 支持哪些存储方式？

**A**: 
- 本地存储
- SMB网络共享
- SSH远程存储
- 可扩展：S3、阿里云OSS等

### Q3: AI分类需要联网吗？

**A**: 
- CPU引擎：不需要，本地运行
- NPU引擎：不需要，边缘设备运行
- 所有处理都在本地完成，保护隐私

### Q4: 如何备份数据？

**A**: 
**自动备份**：
- 系统每天自动创建备份
- 保留最近5个备份

**手动备份**：
1. 进入"系统设置"
2. 点击"立即备份"
3. 或运行 `backup-manager.ps1 -Action backup`

### Q5: 如何恢复数据？

**A**: 
1. 运行 `一键恢复.bat`
2. 选择要恢复的备份
3. 确认恢复

### Q6: 支持多人同时使用吗？

**A**: 
- 当前版本：单用户
- 未来版本：支持多用户（计划中）

### Q7: 如何添加ARM设备？

**A**: 
1. 确保ARM设备已启动并联网
2. 在"设备管理"点击"添加设备"
3. 输入ARM设备的IP和端口
4. 测试连接
5. 保存

### Q8: 扫描大量文件时卡顿？

**A**: 
- 这是正常现象，大量文件需要处理时间
- 可以在"任务中心"查看进度
- 建议分批扫描，不要一次性扫描太多

## 故障排查

### 问题1：无法启动服务

**现象**：运行 `python main.py` 报错

**排查步骤**：
1. 检查Python版本（需要3.10+）
   ```powershell
   python --version
   ```

2. 检查依赖是否安装
   ```powershell
   pip list | findstr fastapi
   ```

3. 检查端口是否被占用
   ```powershell
   netstat -ano | findstr :8000
   ```

4. 查看详细错误日志
   ```powershell
   python main.py 2>&1 | tee error.log
   ```

**解决方案**：
- 安装缺失依赖：`pip install -r requirements.txt`
- 修改端口：编辑 `config/global.yaml`
- 结束占用端口的进程

### 问题2：无法登录

**现象**：提示用户名或密码错误

**排查步骤**：
1. 确认使用默认账户：admin / admin123
2. 检查键盘大小写
3. 检查是否开启了Caps Lock

**解决方案**：
- 如果忘记密码，需要手动重置数据库
- 或从备份恢复

### 问题3：媒体扫描无结果

**现象**：扫描完成后没有显示媒体

**排查步骤**：
1. 检查扫描路径是否正确
2. 检查文件权限
3. 查看任务日志

**解决方案**：
- 确认路径存在且有读取权限
- 检查支持的文件格式
- 查看 `logs/scanner.log`

### 问题4：缩略图不显示

**现象**：媒体库中缩略图为空白

**排查步骤**：
1. 检查 `data/thumbnails` 目录是否存在
2. 检查磁盘空间
3. 查看生成日志

**解决方案**：
- 手动创建目录：`mkdir data/thumbnails`
- 清理磁盘空间
- 重新生成缩略图

### 问题5：AI分类失败

**现象**：AI分类任务报错

**排查步骤**：
1. 检查AI引擎是否配置正确
2. 检查模型文件是否存在
3. 查看任务日志

**解决方案**：
- 切换CPU引擎测试
- 重新下载模型文件
- 检查NPU设备连接

### 问题6：设备连接失败

**现象**：无法连接到ARM设备

**排查步骤**：
1. 检查网络连接
   ```powershell
   ping <设备IP>
   ```

2. 检查端口是否开放
   ```powershell
   telnet <设备IP> <端口>
   ```

3. 检查设备服务是否运行

**解决方案**：
- 确保设备和主控在同一网络
- 检查防火墙设置
- 重启设备服务

### 问题7：数据库损坏

**现象**：提示数据库错误

**解决方案**：
1. 停止服务
2. 备份当前数据库（如果有数据）
3. 从备份恢复
4. 或删除数据库重新初始化

```powershell
# 备份
copy data\metadata.db data\metadata.db.bak

# 恢复
一键恢复.bat
```

### 问题8：系统运行缓慢

**现象**：界面加载慢，操作卡顿

**排查步骤**：
1. 检查系统资源
   - CPU使用率
   - 内存使用率
   - 磁盘空间

2. 检查并发任务数

**解决方案**：
- 关闭不必要的任务
- 增加系统内存
- 清理磁盘空间
- 重启服务
